# Carbon Desktop

Carbon Desktop prepares each Minecraft instance independently and supervises its game processes.

## Launch

**Activated generation**

The verified immutable game files selected for an instance and platform. An instance keeps its player data across generation changes.

**Launch plan**

The selected generation, managed Java runtime, entry point and arguments for one requested play mode. Account identity fields still need resolution at the trusted admission boundary.

**Launch decision**

The account service's private judgment about whether the selected identity may start that generation in the requested play mode.

**Run**

One admitted game process tree, owned until its boundary is empty.
